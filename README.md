# predel

Платформа подбора ИТ-специалистов с подтверждением специализации и грейда через опрос и тестирование. Работодатель описывает потребность, находит кандидатов и отправляет персональное приглашение с зарплатной вилкой; публикация вакансии для этого не требуется.

## Текущий статус

Главная страница сохраняет дизайн из предоставленного архива: плавающую шапку, синий акцент, изображение брелоков и исходную композицию. «Попробовать» открывает интерфейсный прототип кабинетов работодателя и кандидата: подбор, фильтры, профили, тестирование и приглашения. Внизу сайта размещены логотипы из шаблона презентации ФСП.

Новый кандидат начинает с анкеты: отрасль, роль, специализация, самооценка грейда, стек, опыт и софт-скиллы. После анкеты проходит тест; подтверждённая категория появляется только при успешной попытке. В подборе остаются шесть готовых демонстрационных профилей.

Данные хранятся в браузере. Создание профиля не является регистрацией аккаунта: серверная авторизация, подтверждение email, база данных и реальная интеграция ФСП пока не подключены.

## Запуск

Нужен Node.js 22.12 или новее.

~~~bash
npm ci --prefix frontend
npm run dev --prefix frontend
~~~

Откройте http://127.0.0.1:5173. «Попробовать» ведёт в подбор кандидатов, «Кандидату» — в анкету нового кандидата. Запрос из формы на главной переносится в поиск. В кабинетах роль переключается в правом верхнем углу; логотип возвращает на главную. Для проверки приглашений сначала пройдите анкету и тест, включите публикацию своего профиля, затем отправьте ему приглашение из кабинета работодателя.

Сборка: `npm run build --prefix frontend`. Проверка интерфейса при работающем сайте: `npm run test:browser --prefix frontend`.

Подробности реализации и границы прототипа — в [описании интерфейса](docs/interface.md).
