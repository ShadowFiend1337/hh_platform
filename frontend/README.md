# Интерфейс predel

React, TypeScript и Vite. Главная страница на `/` сохраняет дизайн из архива. «Попробовать» открывает кабинеты на `/app`; роль и текущая вкладка находятся в URL. «Кандидату» ведёт в личный профиль, запрос из формы на главной переносится в поиск. Данные синтетические, сервер не требуется.

## Запуск из корня репозитория

~~~bash
npm ci --prefix frontend
npm run dev --prefix frontend
~~~

Адрес: http://127.0.0.1:5173. Нужен Node.js 22.12 или новее.

~~~bash
npm run build --prefix frontend
npm run preview --prefix frontend
~~~

Предпросмотр сборки: http://127.0.0.1:4173.

## Проверка

Оставьте сервер разработки запущенным и выполните:

~~~bash
npm run test:browser --prefix frontend
~~~

Проверка использует Chromium из Playwright. Если браузер ещё не установлен, выполните из `frontend`: `npx playwright install chromium`.

Сценарии охватывают переход с главной в кабинеты и обратно, историю браузера, перенос запроса, поиск и сохранение подборки, фильтр ФСП, обязательную зарплату и границы диапазона, приглашение, видимость контактов после принятия, ограничения двух кабинетов, скрытие профиля, успешную и неуспешную проверку грейда, интервал смены категории, сохранение состояния, клавиатуру, контраст и мобильную вёрстку. Скриншоты записываются в `frontend/test-results/` и исключены из Git.

## Структура

- `src/App.tsx` — навигация, выбор роли, состояние и диалоги.
- `src/model.ts` — демонстрационные данные, подбор и правила доступа в интерфейсе.
- `src/questions.ts` — отдельные демонстрационные программы Frontend/Backend для Junior/Middle.
- `src/pages/` — главная страница, кабинеты, приглашения, профиль компании и тестирование.
- `src/landing.css` — стили исходной главной, ограниченные её контейнером.
- `src/components/` — логотип, примеры кабинетов, модальное окно, профиль кандидата и форма приглашения.
- `public/brand/` — оригинальный логотип ФСП и полоса логотипов, извлечённые из предоставленного PPTX.
- `public/assets/fonts/` — локальный Manrope с исходной лицензией OFL.
- `public/assets/images/` — оригинальное изображение брелоков из архива.

Дизайн главной, изображение брелоков и файл фиксации зависимостей взяты из React-части `backend.zip`. Тексты и примеры адаптированы под подбор специалистов. Презентационная студия и её API не перенесены: они относятся к другому продукту. Подробности — в [описании прототипа](../docs/interface.md).
