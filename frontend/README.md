# Интерфейс predel

React, TypeScript и Vite. Два кабинета в одной SPA; роль и текущая вкладка находятся в URL. Данные синтетические, сервер не требуется.

## Запуск из корня репозитория

~~~bash
npm ci --prefix frontend
npm run dev --prefix frontend
~~~

Адрес: http://127.0.0.1:5173. Нужен Node.js 22.12 или новее.

~~~bash
npm run build --prefix frontend
npm run preview --prefix frontend
~~~

Предпросмотр сборки: http://127.0.0.1:4173.

## Проверка

Оставьте сервер разработки запущенным и выполните:

~~~bash
npm run test:browser --prefix frontend
~~~

Проверка использует Chromium из Playwright. Если браузер ещё не установлен, выполните из `frontend`: `npx playwright install chromium`.

Сценарии охватывают поиск и сохранение подборки, фильтр ФСП, обязательную зарплату и границы диапазона, приглашение, видимость контактов после принятия, ограничения двух кабинетов, скрытие профиля, успешную и неуспешную проверку грейда, интервал смены категории, сохранение состояния, клавиатуру, контраст и мобильную вёрстку. Скриншоты записываются в `frontend/test-results/` и исключены из Git.

## Структура

- `src/App.tsx` — навигация, выбор роли, состояние и диалоги.
- `src/model.ts` — демонстрационные данные, подбор и правила доступа в интерфейсе.
- `src/questions.ts` — отдельные демонстрационные программы Frontend/Backend для Junior/Middle.
- `src/pages/` — кабинеты, приглашения, профиль компании и тестирование.
- `src/components/` — модальное окно, профиль кандидата и форма приглашения.
- `public/brand/` — оригинальный логотип ФСП и полоса логотипов, извлечённые из предоставленного PPTX.
- `public/assets/fonts/` — локальный Manrope с исходной лицензией OFL.

Программа и файл фиксации зависимостей взяты из React-части `backend.zip`. Презентационная студия и её API не перенесены: они относятся к другому продукту. Подробности — в [описании прототипа](../docs/interface.md).
