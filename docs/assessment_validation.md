# Проверка механики тестирования

Дата: 2026-10-10. Версия банка: 2026.10.4. Команда воспроизведения: `npm run build && npm run validate:assessment`.

Процедура валидации тестирования состоит из трёх частей:

1. **Структура и изоляция** (этот отчёт): каждая форма собирается по одной схеме, ключи не попадают в браузер, задания прошлой попытки исключаются.
2. **Проверка на реальных кандидатах**: более 50 участников, разделяющая сила, повторное прохождение и точность решения — [результаты](assessment_validation_results.md).
3. **Пилот и калибровка в работе**: незачётные пилотные задания, статистика ответов по каждому заданию, автоматический вывод заданий с отрицательной дискриминацией — [динамический банк](dynamic_bank.md).

## Схема формы

Размер авторского банка: 1680. В каждой попытке — 3 темы × 2 слота сложности × 2 задания = 12 зачётных вопросов (сумма авторских уровней 18), плюс до одного незачётного пилотного. Порог 70/100 (9 из 12). Вопросы выдаются по одному, 120 секунд на вопрос. При балле 70–79 добавляется уточняющий блок из 6 свежих заданий, решение принимается по 18. Для каждой программы собраны 200 попыток подряд: проверены число заданий, темы, уровни, исключение заданий прошлой попытки и отсутствие ключей в ответе API.

## Скрытые ответы

Собранные JavaScript-файлы браузера проверены: в них нет текста вопросов банка, идентификаторов семейств и закрытого поля correctOptionId. Ключи хранятся только на сервере. Вопросы и варианты ответов конкретной попытки доступны кандидату; верные ответы API не возвращает. Правила HTTP, повторная отправка, истечение времени, лимиты и восстановление базы проверяются `npm run test:server`; пользовательский путь, перезагрузка и ошибка сервиса — `npm run test:browser` и `npm run test:assessment`.

## Ограничения

В проверке участвовали более 50 реальных кандидатов; результаты агрегированы без персональных данных. Выборку нужно расширять по мере накопления попыток, а фактические параметры новых заданий дополнительно уточняет пилот. Конечный авторский банк можно выучить, поэтому зачётный пул пополняется проверенными сгенерированными заданиями, а сгенерированные выводятся после 150 показов. Подробности прокторинга — [assessment_integrity.md](assessment_integrity.md).
