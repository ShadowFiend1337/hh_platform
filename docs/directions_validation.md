# Проверка специализаций и отраслей

Дата: 2026-10-06. Банк: 2026.10.2.

Общий словарь `shared/catalog.ts` содержит 13 специализаций и 25 отраслей. Он используется в анкете, профиле, импорте резюме, подборе и проверке отрасли на сервере. Для всех направлений есть программы Junior и Middle: 26 программ, 156 семейств, 624 вопроса, 28 синтетических описаний вакансий. Мобильная программа проверяет общие принципы, не требует знания конкретной Android/iOS-библиотеки.

| Проверка | Фактический результат | Команда |
| --- | --- | --- |
| Сборка | TypeScript и Vite прошли | `npm run build` |
| Сервер | 44 проверки прошли; включают все направления, неизменность результатов, SQLite и закрытые ключи | `npm run test:server` |
| Импорт и подбор | 16 проверок прошли; роли, неоднозначность, отрасли, ML и точные названия технологий | `npm --prefix frontend run test:resume-parser` |
| Механика банка | 5200 попыток, сохранены темы, сложность и исключение последних двух вариантов; банк отсутствует в сборке браузера | `npm run validate:assessment` |
| Путь ML-кандидата | Импорт → анкета → серверный тест → категория → перезагрузка → подбор; проверены ответы API всех 26 программ | `npm run test:directions` |
| Мобильный интерфейс | 320 px, без горизонтальной прокрутки, проверки axe WCAG 2 A/AA и 2.1 AA прошли | `npm run test:directions` |

Путь ML-кандидата прошёл на Vite `127.0.0.1:5173` и собранном сайте `127.0.0.1:8787`. Дополнительно прошли существующие `test:browser`, `test:assessment` и `test:resume`: анкета, грейд, приглашения, сохранение, приватность, OCR и мобильные сценарии. Оформление формы сохранено.

Четыре предоставленных PDF повторно прочитаны локально. В двух явно указанных ML-ролях импорт добавляет специализацию; оба документа дают по 11 полей. Грейд и согласие не выводятся из опыта или роли. Личные файлы, имена и контакты в отчёт и Git не включены. Дополнительный прогон на личных файлах запускается через переменную `PREDEL_RESUMES` с путём к локальной папке и `npm run test:directions` при работающем Vite.

Технология Android не меняет явно указанную роль ML Engineer. Несколько разных профессий, например UX Designer / Backend Developer, требуют ручного выбора. Fullstack с упоминанием Frontend/Backend остаётся самостоятельным направлением. Поиск React Native не требует отдельного React, если он не указан отдельно; SQL не совпадает с буквами внутри PostgreSQL.

Это технические результаты. Фактическая сложность и достоверность грейда ещё требуют исследования на кандидатах по [плану валидации](metrics_and_validation.md).
