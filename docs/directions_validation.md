# Проверка специализаций и отраслей

Дата: 2026-10-06. Банк: 2026.10.3.

Общий словарь `shared/catalog.ts` содержит 13 специализаций и 25 отраслей. Он используется в анкете, профиле, импорте резюме, подборе и проверке отрасли на сервере. `shared/grading.ts` определяет пять грейдов: Стажёр, Junior, Middle, Senior и Lead. Для всех направлений есть отдельные программы каждого уровня: 65 программ, 390 семейств, 1560 вариантов задач, 67 синтетических описаний вакансий. Мобильная программа проверяет общие принципы, не требует знания конкретной Android/iOS-библиотеки.

| Проверка | Фактический результат | Команда |
| --- | --- | --- |
| Сборка | TypeScript и Vite прошли | `npm run build` |
| Сервер | 87 проверок прошли; включают все направления и грейды, неизменность результатов, SQLite и закрытые ключи | `npm run test:server` |
| Импорт и подбор | 47 проверок прошли; расчёт стажа, пять грейдов, роли, неоднозначность, отрасли, ML и точные названия технологий | `npm --prefix frontend run test:resume-parser` |
| Механика банка | 13000 попыток, сохранены темы, сложность и исключение последних двух вариантов; банк отсутствует в сборке браузера | `npm run validate:assessment` |
| Путь ML-кандидата | Импорт → анкета → серверный тест → категория → перезагрузка → подбор; проверены ответы API всех 65 программ | `npm run test:directions` |
| Пять грейдов | Для каждого уровня импорт, объединение периодов стажа, своя серверная программа, подтверждённая категория, сохранение и поиск | `npm run test:grades` |
| Мобильный интерфейс | 320 px, без горизонтальной прокрутки, проверки axe WCAG 2 A/AA и 2.1 AA прошли | `npm run test:directions` |

Текущий путь ML-кандидата прошёл на Vite `127.0.0.1:5173`; прежний прогон банка 2026.10.2 также проходил на собранном сайте. Новый путь всех пяти грейдов прошёл на Vite и собранном сайте `127.0.0.1:8787`. Дополнительно прошли `test:assessment` и `test:resume`: анкета, грейд, сохранение, приватность, OCR и мобильные сценарии. `test:browser` при первом прогоне остановился по таймауту получения результата второй попытки; повторный полный прогон прошёл, включая приглашения и доступность. Причина первого таймаута отдельно не установлена.

В прежнем прогоне четыре предоставленных PDF повторно прочитаны локально. В двух явно указанных ML-ролях импорт добавлял специализацию; оба документа давали по 11 полей. После расширения грейдов весь этот набор повторно не оценивался. Явно написанный уровень в желаемой роли или метке импортируется, но стаж не назначает грейд, а согласие кандидат даёт отдельно. Личные файлы, имена и контакты в отчёт и Git не включены. Дополнительный прогон на личных файлах запускается через переменную `PREDEL_RESUMES` с путём к локальной папке и `npm run test:directions` при работающем Vite.

Технология Android не меняет явно указанную роль ML Engineer. Несколько разных профессий, например UX Designer / Backend Developer, требуют ручного выбора. Fullstack с упоминанием Frontend/Backend остаётся самостоятельным направлением. Поиск React Native не требует отдельного React, если он не указан отдельно; SQL не совпадает с буквами внутри PostgreSQL.

Это технические результаты. Фактическая сложность и достоверность грейда ещё требуют исследования на кандидатах по [плану валидации](metrics_and_validation.md).
