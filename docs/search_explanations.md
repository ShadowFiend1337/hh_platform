# Объяснение подбора

Объяснение показывает, на каких опубликованных данных основан результат и какие факторы действительно участвуют в текущем порядке. Оно не является вероятностью успешного найма или доказательством качества поиска.

Серверный модуль [search-explanations.mjs](../server/search-explanations.mjs) дополняет уже отобранные и упорядоченные результаты. Он сохраняет состав выдачи, порядок, нейронные оценки и результаты теста. Подключение выполняется после действующей сортировки и до выбора категории и страницы результатов. Изменение формулы ранжирования в эту правку не входит.

В ответе поиска доступны текст `reason` для существующего раскрывающегося пояснения и структурированный объект `explanation`. В обычной карточке дополнительные подписи не нужны.

| Поле | Содержание |
|---|---|
| `category` | Подтверждённая категория и её происхождение. Для демопрофиля категория обозначается учебной. Без теста желаемый грейд не выдаётся за подтверждённый. |
| `evidence` | Фрагмент, выбранный поиском из опубликованных задач либо роли и навыков. Отсутствие фрагмента сообщается явно. |
| `conditions` | Только фактически совпавшие условия: навыки, формат, город, отрасль, бюджет, опыт и другие выбранные ограничения. Неизвестные данные не считаются совпадением. |
| `test` | Наличие результата и его роль в данном порядке: сравнение близких профилей одной категории, сортировка без текстового запроса либо отсутствие влияния. |
| `fsp` | Различие демонстрационных, подтверждённых провайдером, неподтверждённых и отсутствующих достижений. Ввод ID или произвольного флага подтверждения не считается доказательством. |
| `ordering` | Сравнивался ли профиль с близкими кандидатами той же категории и сохранилось ли его положение после действующей сортировки. |
| `relevance` | Смысловая выдача, фильтры или ближайший профиль при отсутствии точных совпадений. |

При поиске по смыслу категория, результат теста и ФСП не подменяют профессиональное соответствие. Пояснение восстанавливает сравнительные группы по той же границе от лучшего участника группы, которую использует существующий модуль ранжирования. Профили другой категории и ближайшие результаты не объединяются с точными совпадениями. Если близкого кандидата для сравнения нет, пояснение не утверждает, что тест или достижение изменили положение.

Без текстового запроса пояснение описывает действующую последовательность: результат теста, затем ФСП при равенстве результата, затем стабильный порядок равных профилей. Само пояснение эту последовательность не меняет.

Для настоящего аккаунта с учебной привязкой `fsp-demo` объяснение прямо сообщает: достижения получены из демонстрационного провайдера, личность не подтверждена. Это не реальная проверка ФСП. Источник определяется доверенным серверным resolver; данные анкеты и самостоятельные заявления кандидата не создают подтверждение. Отозванные достижения не получают вклад в порядок.

Короткий фрагмент основания очищается от email и телефонов. В объяснение не включаются внешние идентификаторы ФСП, контактные данные, токены, правильные ответы на тест и внутренние документы модели. Очистка текста не заменяет контроль доступа к исходным данным.

Проверка: `node --test server/tests/search-explanations.test.mjs`. Тесты покрывают неизменность порядка и оценок, реальные границы сравнительных групп, отдельное отображение неподтверждённого грейда, отсутствие фиктивного вклада ФСП, демонстрационный источник настоящего аккаунта, фактическое совпадение условий и очистку фрагментов. Эти проверки подтверждают корректность пояснений; они не измеряют качество смыслового поиска и найма.
